# Wilson Kinyua Portfolio (CV / Resume)

Next.js implementation of [Wilson Kinyua's Portfolio v2024](https://www.figma.com/design/zKQOEBda9uFkKC40TRUmwj/Wilson-Kinyua-s-Portfolio-v2024--Community-?node-id=1-2) (Figma Community, CC BY 4.0).

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons

## Getting started

```bash
cd cv-resume
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
